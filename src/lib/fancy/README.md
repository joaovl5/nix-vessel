# a super fancy lib™

This library exists mainly for:

- Aliasing some stuff from nixpkgs into kebab-case, having wrapper around some of it maybe
- Adding some helper functions for general Nix and nixpkgs usage
- Having a more functional-style syntax, at cost of relying on the experimental `pipe-operators` feature

It's supposed to be independent from `nix-vessel` and will likely be split into its own repo eventually.
