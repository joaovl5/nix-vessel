# Sketchpad

## Ideas

There should be a clear stack that is opt-in and with modules that can be used separately:

- `nix-fancy` - helper functions layer
- `nix-vessel` - manages core modularity of the shell with basic options
- `nix-vessel-addons` - batteries-included stuff in opinionated form - language support, formatters, etc
- `nix-vessel-ark` - abstraction on top of an input pinning mechanism, e.g. tack, with CLI and other helper scripts to manage bootstrapping and management of developer environments
